# Инструкции для Codex

Единственный источник правил репозитория это `CLAUDE.md`. Прочитай его первым и следуй ему целиком, включая источники истины и цикл работы. Этот файл только переводит то, что в Codex устроено иначе.

## Эквиваленты skills Claude Code

`CLAUDE.md` называет skills, которых в Codex нет. Выполняй их суть:

- `superpowers:writing-plans`: напиши `docs/plans/phase-N.md` сам. Каждая задача: цель, затрагиваемые файлы, шаги, критерий готовности, тесты, зависимости от других задач. Размер задачи 1–3 часа.
- `superpowers:test-driven-development`: сначала падающий тест, затем минимальная реализация, затем рефакторинг. Тесты запускаются после каждого шага.
- `superpowers:executing-plans` и `superpowers:subagent-driven-development`: одна задача из плана за сессию, без субагентов. Прочитай её и затронутые разделы `docs/architecture.md`, реализуй, прогони тесты, отметь чекбоксы задачи в плане.
- `superpowers:verification-before-completion`: перед словом «готово» запусти тесты и статический анализ и приведи их вывод. Утверждение без вывода не считается проверкой.
- `/code-review`: перечитай собственный диф против `docs/architecture.md` и `CONTEXT.md` по четырём пунктам: границы модулей, ключи прав вместо имён ролей, термины словаря, обновлённые документы.

## Границы сессии

Одна сессия равна одной задаче плана. Если задача оказалась больше, раздели её в плане и заверши первую часть с зелёными тестами, а не тяни всё в одном изменении.
