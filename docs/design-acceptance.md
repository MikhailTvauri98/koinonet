Оба решения заказчика вошли в приёмку. На странице участников общий отказ показывается один раз с повтором загрузки, отдельная ошибка состава сохраняет свой повтор. Даты конфликтов и многодневных строк показывают год только для другого года по времени церкви, без «г.».
