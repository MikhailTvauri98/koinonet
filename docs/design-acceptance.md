Проверки опираются на реально выполненные визуальные наборы, принятые задачи1–9 и результаты настоящего E2E ниже.

- Общая мобильная шкала h1 1.25rem сохраняет полное увеличение текста. Ограничены повторные внутренние поля карточек и контролов; фиксированные подписи не разрываются из-за вложенных отступов. Длинные пользовательские строки продолжают переноситься.
- Строки чатов с непрочитанным и списки с фотографиями переходят на дополнительные строки; название не сжимается между изображением и счётчиком. В заголовке чата группа аватара/названия и меню переносятся по доступной ширине, сохраняя 44px цели.
- `MessageList` сохраняет прежнее намерение следовать последнему сообщению при событии прокрутки, пришедшем раньше `ResizeObserver` после изменения высоты. Ручное чтение истории и якорь при подгрузке сохранены. Отдельная задержанная загрузка реальных JPEG проверяет следование, чтение и короткое окно.
- Слоты, карточки, категории уведомлений, приглашение, действия iCal и шаблона сохраняют читаемые слова; нативная дата шаблона целиком помещается с календарём. Восстановлены промежутки действий и семантические списки вложений без лишних маркеров.
- Под заполненными нативными полями даты/времени события показано полное выбранное местное значение, включая секунды. Связь `aria-describedby`, обновление при редактировании и прежний UTC-payload проверены. Это небольшое дублирование значения на широком экране сохраняет доступность времени при большом тексте без смены модели или нативного редактирования.
- Настоящая навигация впервые проверила все12 разделов и выявила запрос шаблонов с `archived=false`, который сервер отклонял422. Клиент передаёт `0/1`; профильный RED→GREEN проверяет исходное состояние, служение и архив, а E2E явно проверяет оба положения фильтра. Уточнены устаревшие селекторы поля роли и подписей прав с видимыми пояснениями; серверные проверки сохранены.

## Фото, API и границы доказательств

В `tests/visual/fixtures/` находятся настоящие публичные фотографии NASA: квадрат 500×500, портрет 500×637 и альбомная 960×612; происхождение, точные URL и public-domain лицензия указаны в README. Проверяются декодированные размеры/пропорции, cover-crop, вложения, недоступное изображение, доступная ссылка, локальный предпросмотр, длинное имя, удаление/повтор и состояние отправки. Пользовательские или сгенерированные фотографии не используются.

Управляемые ответы с реальными байтами доказывают отображение браузером. Они не доказывают серверные права или доставку через nginx. Настоящий E2E запускается отдельно:

```powershell
$env:E2E_API_RUNTIME = 'docker'
$env:E2E_BROWSER_CHANNEL = 'msedge'
npm run e2e
```

`e2e/environment.ts` и guard изолируют базу **church_e2e** и Redis **14/15**. Существующие dev-данные не сбрасываются. Для локальной проверки нужны API vendor/.env, Docker и только postgres/redis; временные API/Reverb/preview запускает существующий harness. Исходное состояние сервисов записывается, после проверки останавливаются только запущенные для неё сервисы. E2E PHP-сервера и прокси не подтверждает production-доставку `X-Accel-Redirect` nginx; она остаётся границей этой приёмки.
