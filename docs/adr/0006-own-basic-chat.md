# Свой базовый чат вместо Telegram или встраиваемого мессенджера

Чат в системе нужен ради связки с остальным: чат создаётся вместе со служением и повторяет его состав, чат события собирает назначенных, права модерации берутся из ролей. Ни ссылки на Telegram-группы, ни встраивание Matrix или Rocket.Chat этого не дают. Принято строить собственный чат с жёстко ограниченным набором функций: текст, картинки, файлы, ответ на сообщение, правка и удаление своих, непрочитанное, закрепление, пуши с отключением звука по чату.

## Рассмотренные варианты

- Telegram-группы плюс бот для уведомлений. Отклонено: нет единой идентичности и автоматического состава.
- Matrix (Synapse) или Rocket.Chat. Отклонено: тяжёлая инфраструктура, чужой UX, и клиент всё равно пришлось бы писать свой.

## Последствия

- Оценка: около месяца работы одного разработчика; чат идёт последней фазой.
- Не в v1 и, скорее всего, никогда: сквозное шифрование, звонки, треды, пересылка, поиск. Реакции и голосовые первые кандидаты на v1.1.
- Общение за пределами служений и событий может остаться в Telegram, система на это не претендует.
