# Модульный монолит на Laravel с клиентом-PWA на Nuxt

Система строится для одной церкви одним разработчиком, который знает PHP и предпочитает Nuxt. Выбран один деплоируемый монолит на Laravel с модулями-неймспейсами, одна Postgres, и единственный клиент: PWA на Nuxt, устанавливаемая на домашний экран. Нативные приложения, микросервисы и BaaS (Firebase, Supabase) отклонены: они удорожают разработку и сопровождение, а для внутренней системы отсутствие в магазинах приложений это плюс, не минус.

## Последствия

- На iOS пуши работают только в установленной на экран «Домой» PWA (iOS 16.4+). Приложение обязано вести пользователя через установку.
- API проектируется без привязки к клиенту: нативный клиент можно добавить позже, включив токены Sanctum, без переделки бэкенда.
- Один сервер и один процесс каждого вида: горизонтальное масштабирование не закладывается.
