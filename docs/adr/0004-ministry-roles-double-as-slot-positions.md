# Роль служения одновременно является позицией для слотов

Календарю нужно выражать потребности вида «2 вокалиста и 1 звукорежиссёр», а системе прав нужны роли внутри служения. Вместо двух понятий (роли для прав, позиции для слотов) принято одно: роль служения. У роли может быть пустой набор прав, и любую роль служения можно указать как требование слота. Есть также свободные слоты без требуемой роли, только с подписью.

## Рассмотренные варианты

- Отдельная сущность «позиция». Отклонено: лидерам пришлось бы вести два почти одинаковых списка, а в интерфейсе объяснять разницу.

## Последствия

- В служении появятся роли без прав («Вокалист») рядом с ролями без слотов («Лидер»). Это нормально.
- Роль, на которую ссылаются слоты активных шаблонов или будущих незавершённых событий, удалить нельзя, пока ссылки не убраны. Интерфейс показывает, где роль используется.
- Слот «N × Участник» означает «любой участник служения», потому что роль по умолчанию есть у каждого.
